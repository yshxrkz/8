# Zaib Ali - Portfolio

Personal portfolio site: about, resume and contact pages. Plain HTML, CSS and JavaScript, no build step.

Based on the MIT-licensed [vCard personal portfolio](https://github.com/codewithsadee/vcard-personal-portfolio) template by codewithsadee.

## View it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish with GitHub Pages

1. Merge this branch into the repository's default branch.
2. In the repository go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick the default branch and the `/ (root)` folder, then save.
4. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Editing

- Text and layout: `index.html`
- Styling: `assets/css/style.css`
- Avatar: replace `assets/images/avatar.svg` with a photo and update the `<img>` in `index.html`
